Biometic Fish Sensor

Project inspired by the lorenzini in sharks that allow them to detect fish by sensing their electromagnetic fields
Attempt to create electromagnetic sensor which can filter for small signals and detect fish when immeresed in water
Project combines PCB design, embedded systems, signal processing, and 3d modleing skills
If successful, project success could translate to biomedical use development

Project started: 2025/05/22
Current Stage of Development: research & simulation
Tools: Altium for PCB design, Solidworks for 3D modeling, Arduino IDE for programming, and Matlab for simulation
