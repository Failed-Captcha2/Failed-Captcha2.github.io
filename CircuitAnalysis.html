Circuit Analysis Program

Personal individual project | Github Repo

Concept:
The goal of this project is to make a tool which can be used to allow students learning circuit analysis techniques to practice using them The program will allow users to build circuits and calculate voltage and current through each component The program will allow users to use voltage node, mesh current techniques to analyse circuits The program will allow for source transformation similar techniques to be applied

Tools:
Unity, Visual Studio Code, C# code

Current Progress/Functionality: All objects contain ManageCollisions script, which tracks collisions, including those through wires, and updates on collision enter/exit Node voltage calcualted using ohm's law
